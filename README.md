# AgroCalc

Android-приложение для учёта хозяйства на Kotlin и Jetpack Compose. Данные хранятся локально на устройстве.

## Возможности

- Учёт поголовья и расчёт потребности в кормах на 30 дней.
- Склад кормов и воды: приход, списание и журнал кормления.
- Доходы и расходы в тенге.
- События с животными, учёт веса и ветеринарные записи.
- Резервное копирование и восстановление JSON.
- Экспорт отчётов в CSV и PDF.

## Установка готового APK — без сборки

Android Studio и компьютер не нужны. Требуется Android 7.0 (API 24) или новее.

1. Откройте [Releases](https://github.com/nikalaswarik123/AgroCalc/releases).
2. В разделе **Assets** скачайте **AgroCalc-1.0-debug.apk** на Android-устройство. Архивы **Source code** содержат исходники, а не установщик.
3. Откройте APK и установите приложение. Если Android запросит разрешение на установку из выбранного браузера или файлового менеджера, предоставьте его для этой установки.
4. Запустите **AgroCalc** из списка приложений.

APK в первом выпуске — тестовая сборка с debug-подписью. При обновлении уже установленного приложения подписи должны совпадать. Перед удалением предыдущей версии обязательно экспортируйте резервную копию JSON, чтобы затем восстановить данные.

В релизе также доступен файл **SHA256SUMS.txt** для проверки контрольной суммы APK.

## Самостоятельная сборка

Откройте корневую папку проекта в Android Studio, настройте Android SDK и выполните синхронизацию Gradle. Путь к SDK можно указать в локальном файле `local.properties`; он не включается в Git.

Конфигурация проекта: SDK 37, minSdk 24, AGP 9.5.1, Gradle 9.6.0, JDK 25 для Gradle Daemon.

Windows:

```powershell
.\gradlew.bat assembleDebug
.\gradlew.bat testDebugUnitTest
```

Linux / macOS:

```sh
chmod +x gradlew
./gradlew assembleDebug
./gradlew testDebugUnitTest
```

Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

Также приложение можно запустить на подключённом устройстве или эмуляторе кнопкой **Run** в Android Studio.

## Сборка на GitHub

Workflow **Build and publish APK** собирает APK, выполняет unit-тесты, рассчитывает SHA-256 и публикует файл в GitHub Release. Вкладка **Actions** содержит журнал сборки и архив **AgroCalc-APK**.

Текущий workflow предназначен для первого выпуска `v1.0.0`. Перед новым выпуском измените версию приложения, имя APK и тег релиза. Повторный запуск с уже существующим тегом не перезаписывает опубликованный выпуск.
